Click Up Widget 取扱説明書

作業を中断するとき、「どこで止めたか・次どこから再開するか」を ClickUp にワンタッチで残せる常駐ツールです。

キーボードの Ctrl + Shift + Space を押すと、画面の右下に 小さな入力ウィンドウが出ます。タスク名とメモを入れて Ctrl + Enter を押すだけで、 ClickUp にタスクが登録されます。

動作要件 Windows 10 / 11 と、ClickUp のアカウント（無料プランで動きます）。 他に入れるものはありません。

1. 入れる・最初の設定

画面の指示どおりに進めれば終わります。この説明書を読まなくても設定できます。

  1. 配布された zip ファイルを解凍します
  2. 「ClickUpWidget」フォルダごと、好きな場所に移動してください（例: C:\Tools\ClickUpWidget\）
  3. フォルダの中の 「ClickUpWidget を起動」 をダブルクリック（黒い画面が一瞬出ますが、そのままで大丈夫です）
先に置き場所を決めてください あとからフォルダを移動すると、自動起動の設定が壊れます。

1ClickUp とつなぎます

「ClickUp の設定画面をひらく」を押すとブラウザが開きます。 そこで API Token の Generate（または Copy）を押し、 コピーされた文字を欄に貼り付けて「次へ」。

API トークンは「あなた専用の鍵」です。他の人に教えないでください。

2デフォルトの登録先を決めます

「Personal Work space」にあるあなたのパーソナルリストが、最初から選ばれています。 そのまま「次へ」で構いません。

ここで決めるのは「ふだんの入れ先」です。ここにしか登録できなくなるわけではありません。 登録するときに、その 1 回だけ別のリストへ入れることもできます。

あなたの名前のリストが見つからなかったときは、何も選ばれていない状態で出ます。 その場合は一覧から 1 つ選んでください（上の欄に名前を打つと絞れます）。

3あと少しです

「パソコンを起動したら自動ではじめる」にチェックが入った状態で「はじめる」を押します。

チェックを入れておくと、サインインするたびに裏で待機します（画面には出ません）。

4準備ができました

呼び出しキーが出たら完了です。「閉じる」を押してください。

以降は Ctrl + Shift + Space でいつでも呼び出せます。

フォルダの中身について

解凍すると次の 4 つが入っています。触るのは 1 つ目だけです。

ClickUpWidget を起動 ← これをダブルクリック 取扱説明書.html ← このファイル app ← 本体と設定（config.json はこの中） runtime ← 動かすのに必要な部品。触らないでください 設定を解除するとき ← 自動起動をやめたくなったときだけ開く
トークンの保存について 貼り付けたトークンは、このパソコンのこのアカウントでしか読めない形に変換してから app\config.json に保存されます。ファイルを開いても文字列は読めません。
このため、設定を済ませたフォルダを別のパソコンやアカウントへコピーしても、そのままでは使えません （初回設定からやり直しになります）。人に渡すときは、配布された zip をそのまま渡してください。

2. 使い方（登録する）

Ctrl+Shift+Spaceウィンドウを呼び出す
Ctrl+Enter登録して閉じる
Esc登録せず閉じる
  • タスク名 … 「どこで止めたか」を一言で
  • メモ … 「次どこから再開するか」のヒント（任意）

打った名前がそのままタスク名になります。日付は期限として持たせるので、 名前に入れる必要はありません（3. 登録先・担当者・期限を変える）。

メモ欄の下書き

呼び出した時点で前に開いていたウィンドウの名前が、メモ欄にあらかじめ入ります （上の画像では「見積書_呉服橋.xlsx - Excel」）。そのまま登録しても、消して書き直しても構いません。

出したまま別の作業をして、もう一度 Ctrl+Shift+Space で戻したときは、 そのときの作業先に入れ替わります。ただしタスク名を打ちかけていたり、メモを自分で書き直していた場合は そのまま残ります。

3. 登録先・担当者・期限を変える

メモ欄の下に、いまの登録先が 3 つ並んでいます。押すと選択パネルが出ます。

⌗ リスト登録先のリスト（クリック または Ctrl+L）
@ 担当者担当者（クリック または Ctrl+U）
◷ 期限期限（クリック または Ctrl+D）
  • 上下キーで選んで Enter、またはクリックで決まります
  • リストは名前だけでなく、入っているフォルダ名でも探せます
    例：「grand kyoto」で 2 件出たら、「hotel archive kyoto」で絞れます
  • 担当者は名前でもメールアドレスでも探せます
  • リスト名も担当者名もアルファベットなので、パネルを開くと入力モードが自動で半角英数に切り替わります
  • やめるときは、パネルの外（上のあいたところ）をクリックするか Esc

期限は 6 つから選べます

始まりの日は中断した日のままで、期限だけが動きます。

今日その日じゅう（はじめはこれ）
明日翌日まで
3日以内3 日後まで
今週中直近の金曜日まで（土日に選ぶと翌週の金曜）
1週間7 日後まで
期限なし期限を付けない

変えた場所は白く反転します

「いつもと違うところに入れようとしている」と気づけるようにするためです。

変えた内容はその 1 回かぎりです。 次に呼び出したときは、いつものリスト・自分・今日に戻ります。

4. よく使うものを上に出す（★）

リストや担当者のパネルで行にマウスを乗せると、右端に ☆ が出ます。 押すと ★ になり、次からその候補が上のほうに出るようになります。

何も打っていないとき★ → 最近使った → いつものリスト → 残り の順
文字を打ったとき同じくらい当てはまるものの中で ★ が先
外したいときもう一度 ★ を押す
同じ名前のリストがあるとき 上の画像のように Grand Hotel Kyoto が 2 つある場合、自分が使う方に ★ を付けておくと、 毎回フォルダ名で見分けずに済みます。

5. 最近登録したタスク

入力欄の下に、まだ終わっていないものが登録の新しい順に最大 5 件出ます （3 件ぶんが見えていて、残りはスクロールすると出てきます）。

いつものリストの分だけでなく、リストを跨いで集めます。 その場で別のリストへ入れた分もここに出るので、どこへ入れたか忘れても見失いません。 いつものリスト以外のものは、2 行目にリスト名が付きます。

行をクリックClickUp でそのタスクを開く
左の丸をクリックその場で完了にする
丸を押したときは、ClickUp 側が実際に変わったことを確かめてから行を消します。 変わらなかったときは行が残り、理由が出ます（消えたのに ClickUp 側はそのまま、という状態を作らないためです）。

6. 一覧を広げて見る

「最近登録したタスク」の右にある 「広げる」（または Ctrl+E）を押すと、 ウィンドウが縦に伸びて一覧だけの画面になります。入力欄はいったん畳まれます。

期限切れきのう以前が期限のもの
今日きょうが期限のもの
今週きょうから今週の金曜まで
すべて期限で絞らない（期限なしのものもここだけに出ます）
↓ ↑期限の並び順を入れ替える（はじめは期限が遠い順）
⟳取り直す
✕入力画面へ戻る（Esc でも戻れます）

期限が過ぎたものは赤、今日のものは 黄色で出ます。 ここに出るのは「自分が担当で、まだ終わっていないもの」で、ワークスペース全体から集めます。

出さないもの

一覧が工程管理のタスクで埋まらないよう、次のものは外しています。

  • 「本工事」「Mockup」「Maintenance」「施工中」のように、工程を表すステータスへ移っているタスク
    （中断メモは作られたときのまま「to do」に居るので、そこで見分けます）
  • config.json の "excluded_lists" に書いたリストのぶん

特定のリストをまるごと出したくないときは、app\config.json にリスト ID を書き足してください。

"excluded_lists": ["900700321909"]

リスト ID は、ClickUp でそのリストを開いたときの URL の末尾の数字です。

7. ネットにつながっていないとき

登録は失敗せず、いったん手元に保存されます。 「接続できないため保存しました」と出たら、その内容は預かった状態です。 つながり次第（5 分ごとに確認します）自動で ClickUp に登録されます。

このとき日付は中断した日のままなので、後から登録されても日付はずれません。

預かった分の登録先リストが後から消されたなど、何度送っても通らないものは、 app\outbox_failed.json へ理由と一緒に移します。捨てはしません。 こうしておかないと、その 1 件が先頭で詰まって後ろの分まで登録されなくなります。

8. 自動起動について

初回設定の③でチェックを入れていれば、もう設定は済んでいます。次のふたつが有効になっています。

自動起動Windows にサインインすると裏で待機します（画面には出ません）
見張り役5 分ごとに常駐の生死を確認し、落ちていれば起動し直します

やめたいとき

フォルダの中の「設定を解除するとき」を開き、次のどちらかをダブルクリックしてください。

  • 自動起動を解除する.bat … サインイン時の自動起動をやめる
  • ウォッチドッグを解除する.bat … 見張り役をやめる

9. 設定を変えたいとき

デフォルトの登録先ごと変えたいときは、初回設定をやり直すのが確実です。

  1. アプリを終了（タスクマネージャーで pythonw.exe を終了）
  2. app フォルダの中の config.json を削除
  3. 「ClickUpWidget を起動」をダブルクリック → 設定画面が最初から出ます

1 回だけ別のリストに入れたいときは、削除する必要はありません。入力画面の ⌗ を押してその場で選べます。

いつもの期限を「今日」以外にしたい

app\config.json に次の行を足すと、それが既定になります。

"default_due_preset": "week"

使えるのは today / tomorrow / d3 / week / d7 / none です。

10. 困ったとき

Ctrl+Shift+Space を押しても何も起きない

アプリが起動していない可能性があります。「ClickUpWidget を起動」をダブルクリックしてください。 起動しても画面には出ません（裏で待機するだけです）。押せば出てきます。

app\pausetask.log を開くと原因が分かります。

「起動しました（ホットキー … 登録済み）」が最後の行 常駐は生きています。念のため常駐を再起動してみてください。
「ホットキーの登録に失敗しました」がある 他のアプリが Ctrl+Shift+Space を先に押さえています。 そのアプリを終了してから常駐を再起動してください。
「FATAL」で始まる行がある 異常終了しています。その内容を控えてください。
何も記録がない／古い日時で止まっている 常駐が落ちたままです。自動起動にチェックを入れていれば、5 分以内に見張り役が起動し直します。

ウィンドウが枠だけになって、中身が表示されない

  1. Esc で閉じて、もう一度 Ctrl+Shift+Space で開き直す
  2. 直らなければ常駐を終了して起動し直す（タスクマネージャーで pythonw.exe を終了 → 「ClickUpWidget を起動」をもう一度ダブルクリック）
この症状では見張り役は反応しません。プロセス自体は生きているため、正常に見えます。

一覧の丸を押しても、行が消えず理由が出る

完了のステータスを送ったのに、ClickUp 側が変わらなかった状態です。 そのタスクに他の人が同時に触っていたか、リストの権限が変わった可能性があります。 出ている理由を控えて、ClickUp でそのタスクを直接開いてみてください。

「ClickUp エラー: 401」が出る

API トークンが無効になっています。ClickUp の Settings → Apps でトークンを再生成してから、 app\config.json を削除して起動し直してください（設定画面が最初から出ます）。

「ClickUp エラー: 404」が出る

登録先のリストが削除されているか、権限が外れています。 app\config.json を削除して起動し直し、リストを選び直してください。

リストや担当者の候補が出てこない／古い

候補は起動したときにまとめて取ってきて app\directory.json に控えています。 1 日経つと自動で取り直します。すぐ反映したいときは常駐を再起動してください （新しく作ったリストや、入ったばかりのメンバーが出ないときはこれです）。

設定を済ませたフォルダを別のパソコンにコピーしたら、初回設定に戻った

仕様です。API トークンはコピー元のパソコンでしか読めない形で保存されています。 移した先で初回設定をやり直してください（トークンは同じもので構いません）。

設定をゼロからやり直したい

app\config.json を削除して起動し直すと初回設定画面が出ます。 同じ場所の directory.json も一緒に消しておくと、候補も取り直します。
